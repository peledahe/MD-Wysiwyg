Guía de Uso y Opciones del Sistema

Modos de Visualización

Alterna instantáneamente entre tres entornos de trabajo desde la barra de menú o barra de acciones:

  • Modo Dividido (Split): Edición simultánea con editor de código fuente a la izquierda y visor WYSIWYG interactivo a la derecha, con scroll sincronizado en tiempo real.
  • Solo Previsualización (WYSIWYG): Vista limpia y modo de edición visual interactiva en tiempo real sin necesidad de ver código Markdown crudo.
  • Solo Editor: Espacio de trabajo enfocado exclusivamente en código Markdown fuente con resaltado y conteo de líneas.

Edición Visual Interactiva (WYSIWYG)

Aplica y remueve formatos directamente en el visor donde esté ubicado tu cursor:

  • Negrita, Cursiva y Tachado: Aplica o quita estilos de tipografía sobre el texto seleccionado.
  • Encabezados (H1, H2, H3) y Citas: Disponen de toggle inteligente: pulsar la opción una segunda vez revierte el bloque a párrafo normal.
  • Listas: Inserta listas ordenadas numéricas o viñetas desordenadas.
  • Inserción Contextual: Enlaces, tablas y diagramas se insertan exactamente en la posición del cursor guardada.

Diagramas, Tablas y Matemáticas

  • Diagramas Mermaid: Generador de Flujo, Secuencia, Gantt, Clases y Estados con renderizado SVG vectorial interactivo.
  • Tablas Markdown: Asistente interactivo para especificar dimensiones (filas y columnas) e insertar la estructura instantáneamente.
  • Fórmulas KaTeX: Renderiza expresiones matemáticas tanto en línea $e=mc^2$ como en bloque $$\sum_{i=1}^n i$$.
  • Resaltado de Código: Bloques de código con sintaxis resaltada para múltiples lenguajes de programación.

Importación y Conversión Inteligente de PDF a Markdown

Convierte documentos PDF en archivos Markdown estructurados y editables mediante el motor integrado de PDF.js:

  • Apertura Directa: Abre cualquier archivo .pdf desde Archivo > Abrir... (Ctrl + O) o arrastrándolo a la aplicación.
  • Jerarquía Tipográfica: Detección automática de encabezados (#, ##, ###) según la escala y tamaño relativo de fuente.
  • Reconocimiento de Formato: Identifica textos en negrita, cursiva, bloques monoespaciados de código y pares clave: valor.
  • Tablas y Listas: Convierte tablas alineadas en sintaxis GFM (| col |) y preserva viñetas y listas numeradas.
  • Edición Inmediata: El contenido se carga al instante en el editor y visor WYSIWYG listo para guardar como .md.

Exporta tu trabajo con un clic a PDF vectorizado de alta calidad o a Página Web HTML independiente. Además, puedes importar cualquier PDF para convertirlo y editarlo como Markdown.
